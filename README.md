# 📊 Análisis de Ventas – Alura Store

Este proyecto consiste en un análisis de datos de ventas de la cadena **Alura Store**, con el objetivo de identificar cuál de sus cuatro tiendas presenta el menor desempeño y debería ser vendida para iniciar un nuevo emprendimiento.

El análisis fue desarrollado como parte de un desafío del curso de **Data Science**, utilizando Python y técnicas básicas de análisis y visualización de datos.

---

## 🎯 Objetivo del proyecto

Analizar el desempeño de las cuatro tiendas de Alura Store considerando:

- Ingresos totales
- Ventas por categoría
- Valoración promedio de clientes
- Productos más y menos vendidos
- Costo de envío promedio (pagado por el cliente)

Con base en estos factores, se emite una **recomendación final** sustentada en datos y visualizaciones.

---

## 🛠️ Tecnologías utilizadas

- **Python 3**
- **Google Colab**
- **Pandas** – Manipulación y análisis de datos
- **Matplotlib** – Visualización de datos
